# Visualization Images

This directory contains the ML model performance visualizations generated during Phase 2 of the project.

## Required Images

To complete the README documentation, the following images need to be added:

### 1. `clause_performance.png`
- **Source**: Phase 2 notebook - Top Clause Performance dashboard
- **Description**: Precision-Recall curves for 10 contract clause types
- **Generated by**: `savefig(fig, "dashboard1_clause_performance")`

### 2. `calibration_quality.png`
- **Source**: Phase 2 notebook - Calibration Quality dashboard
- **Description**: Before vs After calibration analysis with ECE metrics
- **Generated by**: `savefig(fig, "dashboard2_calibration")`

### 3. `roi_analysis.png`
- **Source**: Phase 2 notebook - ROI & Cost-Benefit analysis
- **Description**: ROI waterfall chart and sensitivity analysis
- **Generated by**: ROI analysis section in Phase 2

### 4. `portfolio_risk.png`
- **Source**: Phase 2 notebook - Portfolio Risk Analysis
- **Description**: Risk heatmap and trend analysis
- **Generated by**: `savefig(fig, "dashboard3_portfolio_risk")`

## How to Generate Images

1. Run the Phase 2 notebook (`notebooks/02_phase2_modeling.ipynb`)
2. Execute the visualization cells that generate these dashboards
3. The images will be saved to the `reports/` directory
4. Copy the generated images to this `docs/images/` directory
5. Update the README.md file with the correct image paths

## Image Specifications

- **Format**: PNG
- **Resolution**: 300 DPI minimum
- **Size**: 800x400 pixels recommended
- **Background**: White or transparent
- **Quality**: High resolution for GitHub display
